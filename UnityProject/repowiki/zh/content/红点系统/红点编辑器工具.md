## 简介
红点图全部在编辑器可视化维护：结构（节点/边/分组）、键（key 字典）、状态掩码（六态勾选）。导出产出运行时 JSON 与 key 常量表，三者（源图/JSON/常量表）由导出门禁保证一致。

## 源资产与导入管线
- 源资产：`.reddotgraph` 文件（Project 窗口右键 `Create > 红点图` 创建）
- `RedDotGraphImporter`（ScriptedImporter）负责导入，Inspector 提供 "Open Red Dot Editor" 入口
- `RedDotGraphData` 为源资产真源（节点/边/分组/双字典）

## 编辑器窗口
双击 `.reddotgraph` 资产或 Inspector 按钮打开 `RedDotWindow`（GraphView）：

- 画布：右键创建节点、拖拽连线建父子关系（连线时自动环检测）
- 节点配置：key 与逻辑 ID（externalId，-1=纯聚合）均为字典 + 模糊搜索选择器（可内联新建）；六态掩码勾选框
- 左栏组树面板：分组导航、校验状态、主副组迁移
- 工具栏按钮"使用说明"打开 `RedDotHelpWindow` 帮助窗（纯静态富文本）

## 分组子图与引用节点
- 框选归组：组内是独立完整红点树，**仅组根对外**——组外节点连接组根即消费整组聚合结果
- 主图放**引用节点**拼接组（引用节点替换为组根，导出展平）
- `dynamicMount` 组：不连静态父，运行时经 `SetDynamicParent` 动态挂载（活动期次等场景）

## 双轴校验
实时校验 + 导出门禁双重拦截：

| 轴 | 校验码 | 内容 |
|---|---|---|
| key 轴 | K1-K6 | key 未设置/悬空/重复等 |
| 结构轴 | V1-V9 | 组/边拓扑问题 |

## 导出与产物
工具栏导出按钮 → 双轴校验门禁通过后：
1. 写运行时 JSON：`Assets/AssetRaw/Configs/Other/RedDotGraphConfig.json`（紧凑序列化；分组展平：引用节点替换为组根，边按目标 redDotType 降序）——**文件名即 YooAsset 地址 `RedDotGraphConfig`**
2. 同步再生成 key 常量表 `RedDotKeys.cs`（`<auto-generated>` 头、成员名非法字符转 `_`、按成员名 Ordinal 排序、中文 desc 注释、聚合节点标注不可注册）——**生成物禁止手改**

运行时加载由 `RedDotGraphModule` 按地址 `RedDotGraphConfig` 拉取 `TextAsset` → `AddJsonStr` 建图 → 与 `RedDotKeys` 双向对账（版本错配启动即报）。

> 说明：该 JSON 位于 YooAsset 收集器 Configs tag 覆盖的 `Configs/Other` 目录，但**不是配置表**——配置系统 `InitConfig` 只加载 `*.bytes`，红点 JSON 由红点模块按地址独立加载，互不干扰。

## 菜单总览
红点编辑器实际菜单只有三个：
- `Assets/Create/红点图`：创建源资产
- `Tools/红点系统/生成Key常量表(选导出JSON)`：不进编辑器直接复跑常量表生成（CI 可用）
- `TEngine/RedDot/Build Demo Scene`：一键构建 Demo 场景（`Assets/Scenes/RedDotDemoScene.unity`）

帮助窗（使用说明）由编辑器窗口工具栏按钮打开，无菜单项。
