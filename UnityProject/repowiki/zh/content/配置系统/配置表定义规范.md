## 简介
配置表结构完全在 Excel 表头中声明（无独立 DSL）。工具按 A 列标签行识别结构，不依赖固定行号。本文描述源表的组织方式与各标签、类型的语义。

## 文件与 Sheet 命名
- 文件名支持中英文，按业务自由命名
- A1 首格以 `##` 开头的 sheet 才导出，否则忽略
- sheet 名需为英文且不含特殊字符；**sheet 名即表名**：生成 `{sheet}Item`（数据类）、`{Sheet}Config`（表类）与 `{Sheet}Config.bytes`
- 一个 Excel 可含多个 sheet，每个 sheet 独立导出

## 标签行结构（A 列驱动）
| 标签 | 作用 |
|---|---|
| `##lb-row##` | 整行忽略（保留行），数据区同样生效 |
| `##lb-labels##` | 描述行；列描述以 `#` 开头 = 主键列（仅 int/string，单主键，建议第一数据列）；`~` 前缀 = 组合索引成员列 |
| `##lb-target##` | 输出平台：`c` 仅客户端 / `s` 仅服务端（客户端忽略该列）/ `cs` 双端 / `l` 多语言 / 空 = 双端 |
| `##lb-keys##` | 数据类型（见下节） |
| `##lb-names##` | 字段名（C# 标识符；含空格/换行工具自动移除并报 Error） |

推荐排版（工具按标签匹配，行号不敏感）：

| 行 | A | B | C | ... |
|---|---|---|---|---|
| 1-4 | `##lb-row##` | | | |
| 5 | `##lb-labels##` | `#索引id` | 名称 | |
| 6 | `##lb-target##` | | `l` | |
| 7 | `##lb-keys##` | `int` | `string` | |
| 8 | `##lb-names##` | `id` | `name` | |
| 9+ | （数据从 B 列起，与标签列对齐） | 1001 | 铁剑 | |

> **注意**：主键列若未以 `#` 标记，工具兜底取第 2 列（B 列）。数据行的各列必须与标签行的列位置对齐（A 列为标签列，数据自 B 列起）。

## 支持的数据类型
**通用类型**：`int`、`long`（亦支持 byte/short/uint/ulong 等）、`string`/`str`、`bool`（1,0,TRUE,FALSE）、`double`/`float`（不建议，建议整型万进制 1=10000）

**特殊类型**：
- `vec2`/`vec3`/`vec4`/`vec2int`/`vec3int`：`x,y(,z,w)` 逗号分隔
- `quat`/`quaternion`、`color`
- `datetime`：时间戳或 `DateTime.TryParse` 可解析格式
- 多语言列在 `##lb-keys##` 处类型照填，多语言由 `##lb-target##` 的 `l` 驱动

**复合类型**：数组 `int[]`；列表 `list<T>`（可嵌套）；字典 `dict<K,V>`；元组 `valuetuple<...>`（≤7 元素）

## 自定义复合对象
四种固定格式对象，由共享缓存分析阶段校验（格式错误仅跳过该数据，不终止导表；空数据 `[]`/`[[]]` 合法）：

| 类型 | 格式 | 要求 |
|---|---|---|
| RewardObject | `[[奖励类型,道具id,数量],...]` | 每条目恰 3 元素 |
| ConditionObject | `[[条件类型,参数...],...]` | 每条目 ≥2 元素，不定长 |
| EffectCfgObject | `[效果名,[[参数],...]]` | 恰 2 元素 |
| GradedPriceObject | `[[奖励类型,道具id,数量,档位],...]` | 每条目恰 4 元素 |

## 数据填写规则
- 集合用 `[` `]` 定位、逗号分隔；dict 的 key/value 均以逗号分隔：`["key",1,"key2",[1,2]]`
- 字符串填 `Assets/` 开头的资源路径会自动取文件名（png/jpg 去后缀）
- 尽量避免小数（万进制）
