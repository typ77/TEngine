## 简介
本文描述配置表从资源到内存对象的完整加载链路：初始化时机、按 tag 并发加载、免反射建表、按行懒加载与负缓存、共享缓存还原、多语言表加载。

## 初始化时机
`GameApp.StartGameLogic`（热更入口）中顺序执行，UI 在配置就绪后显示：

```csharp
private static async UniTask StartGameLogic()
{
    await ConfigSystem.Instance.InitLanguage();
    await ConfigSystem.Instance.InitConfig(null);
    GameModule.UI.ShowUIAsync<LoginUI>();
}
```

## ConfigSystem 加载流程
`InitConfig`：
1. `ResourceModule.GetAssetInfos("Configs")` 按 tag 取全部表资产
2. 并发 `LoadAssetAsync<TextAsset>(info.Address)`，`UniTask.WhenAll` 等待
3. 每个资产经 **`ConfigTableRegistry.TryCreate(asset.name)`** 免反射建表；未命中（新表未重新导表）回落 `Assembly.GetType("TEngine.{名}")` + Activator 并告警；仍未命中则释放句柄跳过
4. `SetTextAsset` 解析头部后即释放 TextAsset；单表解析异常仅跳过该表（对称释放），不整体崩溃
5. 全部成功后整体替换 `m_tableCache` 并 `ConfigLoadVersion++`（派生缓存据此失效）

`GetConfig<T>()`：以 `typeof(T).Name` 查缓存（泛型静态缓存避免每次分配字符串），未加载返回 null。

## TableBaseTemp 懒加载
`TableBase.cs` 提供 `ConfigTableBase`（非泛型基类）与 `TableBaseTemp<TKey,TItem>`：
- **加载期**只解析头部：`TotalCount` + key→offset 索引，字节留在 `m_byteBuf`
- **`GetItem(id)`**：命中 `m_cache` 直接返回（零 GC）；未命中按 offset 反序列化并入缓存；全表缓存满后自动清 offsetMap/byteBuf
- **miss 负缓存**：确认不存在的 key 只查一次、只报一次错（`silentIfAbsent` 可静默）
- `GetAllKeys()`：首次从 offsetMap 构建，之后返回缓存列表

## 共享缓存读取
启用共享缓存的表由生成的 `ReadHead` override 先读共享段（字段名→数量→唯一值），填入静态字典；行数据中该字段只存 int 索引，属性 getter 从字典取值（-1 安全返回默认值）。

## 多语言加载
`InitLanguage`：取 `ILocalizationModule.Language` → 加载 `Language_{枚举名}.bytes`（缺失回退 `Language_Default`）→ `LanguageConfig.SetTextAsset` 整体替换（失败保留旧表）；缺失 id 走负缓存只报一次错。`GetLanguageString(id)` 供生成属性（如 `GoodsItem.name`）调用。

## YooAsset 收集配置
收集器（`AssetBundleCollectorSetting.asset` 与同名 XML 双份维护）Configs 组：
| CollectPath | AssetTags | 用途 |
|---|---|---|
| `Assets/AssetRaw/Configs/Bytes` | `Configs` | 表数据（`GetAssetInfos("Configs")` 依赖此 tag） |
| `Assets/AssetRaw/Configs/LanguageBytes` | （空） | 多语言 bytes（按名加载，不入 tag 集合） |

> **注意**：运行时实际读取 `.asset`（ScriptableObject），XML 为镜像，两份必须同步修改。

## 常见问题
| 现象 | 原因/处理 |
|---|---|
| `GetConfig` 返回 null | InitConfig 未完成（时序）；或表 bytes 未被收集器收集 |
| "未找到配置表类型 TEngine.X" | 新表未重新导表更新 ConfigTableRegistry（已回落反射并告警） |
| GetItem 返回 null | key 确实缺失（首次 Log.Error 后负缓存）；或表未加载 |
| 多语言为空 | `Language_*.bytes` 未生成或语言枚举名不匹配 |
| bytes 读取错位 | 生成代码与 bytes 不同批（重新全量导出可修复） |
