## 简介
导表工具为 Unity Editor 插件（`Assets/Editor/ExcelTool/`，Editor-only 程序集），将 `Configs/Tables/` 下的 Excel 解析、校验并生成为 C# 代码与二进制数据，同时维护多语言工作簿与多语言 bytes。

## 工具入口
- 菜单 **`Tools/配置表工具/生成全部数据(数据压缩)`**：全量导出（共享缓存启用），等价 API `ExcelDataTool.BuildConfigBytes()`
- 菜单 **`Tools/配置表工具/数据生成窗口`**：按文件/按 sheet 选择性导出、打开输出目录
- 字节码调试查看器：`Assets/Editor/ExcelTool/BytesViewer/`（查看 .bytes 内容、导出 JSON/CSV、Excel diff）

## 生成产物与命名规则
| 产物 | 位置 | 命名 |
|---|---|---|
| 数据类 | `GameScripts/HotFix/GameProto/GameConfig/{sheet}Item.cs` | `{sheet}Item`，`[Preserve]` 防裁剪 |
| 表工厂注册 | 同目录 `ConfigTableRegistry.cs` | 合并式生成（单表导出不丢注册） |
| 表数据 | `AssetRaw/Configs/Bytes/{sheet}Config.bytes` | 表类名 = bytes 名 |
| 多语言 | `Configs/Language/Localization.xlsx` 回写 → `AssetRaw/Configs/LanguageBytes/Language_{语言}.bytes` | |
| 无缓存对照类 | `Editor/ExcelTool/Report/Generated/{sheet}Uncompressed.cs` | Editor-only 程序集，供压缩率报告 |

> `GameConfig/` 目录全部为自动生成代码（含 `ConfigTableRegistry.cs`），**禁止手动修改**，下次导出覆盖。

## 生成原理
- **解析**：`SheetHeaderReader` 按 A 列标签行构建列类型/字段名/忽略行/主键列/组合索引；数据行主键查重（重复只保留首条）
- **共享缓存**：`SharedCacheAnalyzer` 分析 string/list/dict/复合对象字段重复率，≥8% 自动启用——唯一值入静态字典，行内只存 int 索引；仅顶级字段，string 跳过空串
- **二进制布局**：`[共享缓存段(可选)] [int 行数] [key+offset 索引区] [数据区]`；写侧 temp+rename 原子落盘
- **代码生成**：`TableBase.txt` 模板填充；有共享缓存/组合索引的表自动追加 `ReadHead` override；组合索引表生成 `GetIdByCompoundKey_*` 等查询方法
- **多语言**：`l` 列文本分配 int id（回写工作簿），bytes 内只存 int；运行时经 `ConfigSystem.GetLanguageString(id)` 还原

## 新增配置表流程
1. 在 `Configs/Tables/` 新建 xlsx（建议复制 Goods.xlsx；单 sheet 时 sheet 名与文件名一致）
2. 按规范写表头（标签行结构见 [配置表定义规范](配置表定义规范.md)）
3. 确认版本控制为最新（多语言 id 依赖 Language 工作簿同步提交）
4. 运行 `Tools/配置表工具/生成全部数据(数据压缩)`
5. 验证产物：`GameConfig/{sheet}Item.cs`、`ConfigTableRegistry.cs` 更新、`Bytes/{sheet}Config.bytes`
6. 确认 .bytes 被 YooAsset Configs 组收集（收集器已配置 tag `Configs`，新表自动收）
7. （可选）复杂模块在 `GameLogic/Config/` 封装 `XxxConfigMgr`

## 注意事项与红线
- 字段名/类型确定后不轻易改名删列（热更包前向兼容：新增字段安全，删除/改名不安全）
- **多语言 id 漂移**：导表会回写 Language 工作簿，若未提交工作簿而他人导表，id 可能错位——Language 工作簿必须与表数据同批提交
- 导表结束弹结果对话框，错误详情见 Console（类型不匹配、字段名非法、复合对象元素数不符等）
- 进程中断残留的 `*.tmp` 为原子写临时文件，可安全删除（已被 gitignore 覆盖）
