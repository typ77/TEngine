## 简介
面向业务开发的配置访问指南：如何查询表数据、如何封装管理器、哪些写法会击穿懒加载、多语言如何取文案。

## 基础访问
```csharp
// 单例访问（表类名 = {sheet}Config）
var goods = ConfigSystem.Instance.GetConfig<GoodsConfig>();

// 按 ID 查询（懒加载，命中缓存零 GC）
var item = goods.GetItem(1001);
if (item != null) { /* ... */ }

// 静默查询（不打印缺失日志，配合负缓存）
var maybe = goods.GetItem(9999, true);

// 遍历所有 key（⚠️ 仅冷启动构建索引用，见下文性能治理）
foreach (var key in goods.GetAllKeys()) { }
```

## 生成代码结构
以 `Goods` 表为例（`GameConfig/GoodsItem.cs`）：
- `GoodsItem`：只读属性；`l` 多语言列生成双属性——`nameKey`（int id）与 `name`（经 `GetLanguageString` 还原的字符串）；复合对象列为 `RewardObject` 等强类型
- `GoodsConfig : TableBaseTemp<int, GoodsItem>`：实现 `ReadKey`/`CreateItem`
- `ConfigTableRegistry`：`TryCreate(name, out table)` 工厂，启动免反射建表

## 配置管理器封装（推荐）
有一定复杂度的模块不应在业务中散落 `ConfigSystem.Instance.GetConfig<>()`，应封装 `XxxConfigMgr`（或 CfgLoader）：

```csharp
// GameLogic/Config/GoodsConfigMgr.cs
public class GoodsConfigMgr
{
    private static GoodsConfigMgr _instance;
    public static GoodsConfigMgr Instance => _instance ??= new GoodsConfigMgr();

    /// <summary>获取商品配置，找不到返回 null</summary>
    public GoodsItem GetGoods(int goodsId)
        => ConfigSystem.Instance.GetConfig<GoodsConfig>().GetItem(goodsId);
}
```

- 封装收益：字段改名只改一处；可做预处理/预建索引/校验；接口语义清晰
- 简单的只读一次场景可直接访问，不必强建管理器

## 运行时访问性能治理
懒加载的关键性质：单点 `GetItem(id)` 命中缓存后 O(1) 零 GC；但 `foreach (GetAllKeys()) { GetItem(k); }` 会**击穿懒加载**（首次全表反序列化 + GC spike）。

- 全量遍历只允许出现在**冷启动一次性索引构建**（CfgLoader 强 Init 模式：`Init()` 内建好索引，运行时直查缓存字段）
- 聚合查询（Max/OrderBy/ToDictionary）必须在 Init 期算一次存字段，禁止写成表达式体属性
- 详细反模式清单与治理流程见 skill 文档 `config-access-patterns.md`（`.claude/skills/custom-config/references/`）

## 多语言使用
```csharp
// 生成属性直接拿还原文案
var name = item.name;                                  // 内部 = GetLanguageString(item.nameKey)

// 任意 id 取文案
var text = ConfigSystem.Instance.GetLanguageString(id); // 缺失返回空串并负缓存
```
新增多语言文案：在 Excel 中把列标 `l`，导表自动收集进 Language 工作簿；**工作簿需与表数据同批提交**（详见 [导表工具与流程](导表工具与流程.md) 注意事项）。

## 何时需要重新导表
- 新增/删除/修改表结构或数据后
- 修改了 `Configs/Language/Localization.xlsx` 后（同步多语言 id）
- 生成代码报“类型不存在/字段不存在”而源表无变化时（生成物与代码不同步）
